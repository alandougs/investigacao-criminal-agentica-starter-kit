# O prompt que você usa todo dia

Este é o pedido que o investigador fictício deste laboratório digita, quase igual, toda vez que um documento novo chega ao caso:

```text
faz um resumo desse BO pra mim e vê se tem algo estranho, rapidinho
```

Ele funciona "mais ou menos": às vezes o resumo vem em tópicos, às vezes em texto corrido; às vezes aponta o que falta, às vezes não; às vezes afirma coisas que o documento não diz.

## Sua tarefa (Trilha 1)

1. Para cada bloco do PTCFREE, marque se o pedido acima o contém: **P**ersona, **T**arefa, **C**ontexto, **F**ormato, **R**estrições, **E**xemplo, **E**stilo.
2. Responda: quantas tarefas diferentes esse pedido mistura?
3. Reescreva o pedido no modelo PTCFREE do capítulo, para produzir uma **nota de triagem** do documento, a ser lida pela autoridade policial.
4. Separe a sua versão em duas partes: o que é **fixo** (vale para todo documento) e o que **muda** a cada pedido.
5. Confira o modelo PTCFREE, a tabela fixo/variável e os critérios do laboratório no Cap. 2; confirme cada informação no boletim.
