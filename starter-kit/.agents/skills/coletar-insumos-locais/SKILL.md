# Coletar insumos locais

Leia [regras comuns](references/regras.md). Localize somente os arquivos
autorizados, registre origem e cópias usadas. Copie para trabalho quando necessário
e permitido; preserve originais. Confirme igualdade por SHA-256 com ferramenta
disponível, ou declare que a verificação falta. Não navegue na web nem contate
fontes. Entregue a lista de cópias e limitações, com decisão humana pendente
para qualquer nova fonte.
