# Tratar dados sintéticos

Leia [regras comuns](references/regras.md). Trabalhe sobre cópias. Preserve
valor original e campo normalizado lado a lado, com arquivo e linha. Datas sem
hora continuam sem hora; documento sem data não ganha data estimada silenciosa.
Para somas, use cálculo determinístico, respeitando sinal e unidade. Registre
método e avisos de leitura. Entregue tabela tratada e lista de campos pendentes.
