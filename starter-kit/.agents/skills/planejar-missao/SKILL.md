# Planejar missão

Leia [regras comuns](references/regras.md). Escreva a pergunta, entradas,
produto, limites e critério de conclusão. Separe o que pode ser conferido em
documento do que depende de apuração. Proponha os passos necessários e onde
pedirá decisão humana. Use somente arquivos já indicados. Não execute a análise
se o pedido for apenas de plano; aguarde aprovação quando a proposta ampliar
o escopo autorizado.
