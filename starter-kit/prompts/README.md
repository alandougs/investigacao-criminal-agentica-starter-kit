# Biblioteca PTCFREE

PTCFREE organiza instruções em sete blocos:

1. **P — Persona**
2. **T — Tarefa**
3. **C — Contexto**
4. **F — Formato**
5. **R — Restrições**
6. **E — Exemplo**
7. **E — Estilo**

Os modelos abaixo são pontos de partida. Variáveis entre colchetes devem ser preenchidas pelo leitor. Não use dado real em ferramenta não autorizada. Resultado de IA é rascunho até conferência humana.
